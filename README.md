# Jupiter Hell Classic 한국어 패치 (KR-AOS)

Steam판 **Jupiter Hell Classic**(게임 버전 **0.10.12c**)의 비공식 한국어 패치입니다. 메뉴·설정·아이템·적·특성·유물·도전과제·메시지·도움말 등 게임 안 문구 전반을 번역했습니다.

## 다운로드

오른쪽의 **Releases**에서 최신 `JupiterHellClassic_KR_Patch_vX.X.exe`를 받으세요.

## 설치

1. Steam을 켜 둔 채(게임을 구매한 계정으로 로그인) 게임을 완전히 종료합니다.
2. 받은 exe를 실행합니다. 게임 폴더를 자동으로 찾습니다.
3. **[패치 설치하기]** 를 누릅니다. 원본 실행 파일은 자동으로 백업됩니다.
4. Steam에서 평소처럼 게임을 실행합니다.

## 제거

런처의 **[원래대로 되돌리기]** 를 누르면 원본으로 돌아갑니다. 세이브와 설정은 건드리지 않습니다. Steam의 [게임 파일 무결성 검사]로도 돌아갑니다.

## 알아 두세요

- 게임 버전 0.10.12c 전용입니다. 게임 버전이 다르면 런처가 설치를 막습니다. 게임이 업데이트되면 새 패치가 나올 때까지 기다려 주세요.
- 게임이 업데이트되거나 무결성 검사를 하면 한글이 풀립니다. 런처에서 [패치 설치하기]를 다시 누르세요.
- 옛 `설치.bat`/`제거.bat`(v1.6.1 이하)은 쓰지 마세요.
- 서명되지 않은 프로그램이라 Windows SmartScreen 경고가 뜰 수 있습니다([추가 정보] → [실행]). 일부 백신이 오탐할 수 있으니 릴리즈 페이지의 SHA-256 값으로 직접 검사해 볼 수 있습니다.
- 한글은 완성형 2,350자와 기본 기호만 표시됩니다. 키 이름(Enter, Esc 등)은 영어 그대로 둡니다.

## 라이선스

Jupiter Hell Classic의 바탕이 되는 DRL(GPL v2)과 FPC Valkyrie(MIT)의 소스에 한글 출력 기능을 더해 다시 빌드한 실행 파일(`drl.exe`)이 런처에 들어 있으며, GNU GPL v2에 따라 배포합니다. 변경한 소스가 필요하시면 디스코드로 요청해 주세요. 한글 글꼴은 Noto Sans CJK KR(SIL OFL 1.1)입니다. 게임 데이터와 상표는 ChaosForge의 것이며, 이 저장소와 배포 파일에는 게임 파일이 들어 있지 않습니다. 무료 비공식 팬 번역입니다.
